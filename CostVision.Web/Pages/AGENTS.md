# Правила для папки Pages

## Ответственность и сопровождение

Папка содержит Razor-каркас основных страниц и PageModel-обработчики. Обработчик принимает request и текущего пользователя, вызывает Application use case и возвращает результат через JsonResultMapper; бизнес-логика и финансовый доступ остаются в Application.

После изменения .cshtml, .cshtml.cs и .css непосредственно в этой папке сверить и актуализировать текущую карту страниц, HTTP-контракты и визуальные договорённости в этом файле. При добавлении или переносе страницы обновить также техническое руководство. Подпапки [Settings](Settings/AGENTS.md) и [Shared](Shared/AGENTS.md) имеют собственных владельцев инструкций.

Изолированные проверки PageModel находятся в tests/CostVision.Web.UnitTests/Pages. Прямой вызов handler не подтверждает cookie, routing, antiforgery или production-конвейер. Общая карта описана в [техническом руководстве](../../Documentation/TechnicalGuide/06-web-layer.md).

## Общие правила

- Страницы Razor Pages должны оставаться контейнерами для AJAX-интерфейса: динамические данные загружаются и отрисовываются клиентскими скриптами.
- Для новых клиентских сценариев использовать TypeScript в `CostVision.Web/wwwroot/ts`, а подключать собранные файлы из `dist`.
- Сторонние браузерные библиотеки подключать из `wwwroot/lib` перед использующими их модулями: Chart.js из `lib/chartjs` для Index, html5-qrcode, exif-js и jsQR из отдельных одноимённых папок (`jsqr` для jsQR) для AddReceipt. Их исходники не относятся к нашему TypeScript и не редактируются вручную.
- Не редактировать вручную файлы в `dist`; если изменён TypeScript, собранные файлы должны быть обновлены штатной сборкой фронтенда пользователем.
- Для формовых полей в Razor-разметке задавать и `id`, и `name`; `label` должен ссылаться на `id`.

## Визуальные договорённости

- В `Stores.cshtml` первый столбец таблицы магазинов служебный и содержит кнопку развёртывания группы. Визуально он не должен восприниматься частью таблицы: границы и фон первой ячейки скрыты, а таблица должна начинаться с колонки `Наименование`.

## Текущие страницы

- `AddReceipt.cshtml` - добавление чеков в выбранный счёт через QR-код с камеры, загрузку изображений или ручной ввод фискальных данных.
- `Error.cshtml` - стандартная страница ошибки с отображением идентификатора запроса.
- `Index.cshtml` - дашборд доходов и расходов с выбором периода, группировки, источника расходов, счетов и магазинов.
- `Login.cshtml` - вход пользователя по логину и паролю.
- `Logout.cshtml` - страница выхода пользователя через POST-обработчик.
- `MoneyMovements.cshtml` - список денежных операций с фильтрами, созданием, удалением, переносом между счетами, импортом банковской выписки и привязкой чеков.
- `Products.cshtml` - список товаров с поиском, сортировкой, пагинацией и редактированием адаптивных названий.
- `Receipts.cshtml` - отчёт по чекам за период с группировкой по счетам, просмотром деталей, обновлением, удалением, переносом между счетами и привязкой денежных операций.
- `Stores.cshtml` - список магазинов с поиском, сортировкой, группировкой, пагинацией, редактированием адаптивных названий и просмотром чеков магазина.
- `UserActivity.cshtml` - AJAX-точка для отметки активности пользователя.
- `Settings/UserSettings.cshtml` - настройки текущего пользователя: создание, редактирование, скрытие и совместный доступ к счетам.
- `Settings/Users.cshtml` - административное управление пользователями: поиск, показ неактивных, создание, редактирование, роли и переключение активности.
- `Shared/_Layout.cshtml` - общий каркас приложения с навигацией, подключением стилей, скриптов и antiforgery-токена.
- `Shared/_ValidationScriptsPartial.cshtml` - общий partial для клиентских скриптов валидации.
- `_ViewImports.cshtml` - общие импорты Razor для страниц.
- `_ViewStart.cshtml` - общий выбор layout для страниц.
