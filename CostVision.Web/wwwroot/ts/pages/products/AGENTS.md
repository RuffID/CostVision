# Каталог товаров

## Ответственность

API, состояние и render обслуживают поиск, сортировку, страницы, покупки и изменение названий.

## Контракты и границы

Не переносить права на клиент. Проверять фильтры и обновление строки. AdaptiveName общее для Product; заголовок и подсказка говорят об общем названии и влиянии на списки/отчёты других пользователей. Не обещать персональную настройку.

## Проверка

Проверка типов — npm run build:ts по корневым правилам. Поведение DOM, модальных окон, камеры и запросов требует отдельных сценариев; сборка не подтверждает браузерную приёмку.

## Сопровождение

Этот файл отвечает за собственные исходники непосредственно в данной папке; для дочерних папок действуют их локальные инструкции и общие правила родителей. После изменения исходников в этой папке сверить и актуализировать здесь ответственность, контракты, зависимости и способ проверки в рамках той же задачи. При переносе файлов обновить описания прежней и новой папок. Не добавлять фиктивный журнал или неподтверждённый результат проверки.

Общая карта и порядок сопровождения: [техническое руководство](../../../../../Documentation/TechnicalGuide/12-source-map-and-maintenance.md). Открытые изменения: [план рефакторинга](../../../../../Documentation/Plans/project-refactoring-2026-10-13/README.md).

API разворачивает только проверенный ServiceResult и проверяет обязательную форму данных через shared HTTP-validator: списки, поля результата и серверные страницы/итоги соответствующего сценария. Отказ не заменяется пустым успехом или нулевыми totals; финансовые расчёты остаются серверными. HttpError сохраняется до границы пользовательского действия. Начальные счета, основной список, покупки товара и контекст имени независимы. Смена поиска/запроса, hide и pagehide инвалидируют нужное чтение; AbortSignal доходит до API. Команда имени захватывает ProductId/AdaptiveName, Set блокирует повторный POST того же ID. Новое открытие, включая тот же ID, не получает старый результат/finally; открытая форма доступна после завершения предыдущей команды.

Изолированные requestCoordination.test.mts вызывают actual DOMContentLoaded/controller/API с подставным DOM/fetch и управляемыми Promise; браузер/HTTP/Bootstrap-приёмку этим не закрывать.

Cookies/query page используют shared/preferences, кнопки/диапазон catalog pagination — shared/paging; ProductList расширяет PagedList. Прежние defaults, positive query page и сохранение прочих URL-параметров/hash не изменены. Render отображает серверные данные без HTTP.
