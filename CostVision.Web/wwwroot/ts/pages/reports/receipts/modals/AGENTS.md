# Модальные действия отчёта

## Ответственность

Модули обслуживают удаление чека и просмотр/управление связанными операциями.

## Контракты и границы

Использовать общий стек Bootstrap. Ответ предыдущего чека не должен применяться после открытия следующего; проверять закрытие и повторную инициализацию.

Окно денежных кандидатов показывает явную страницу/count и сбрасывает страницу при изменении фильтра или открытии другого чека. Linked/candidates имеют отдельные координаторы и AbortSignal; снимок фильтров и ревизия открытия исключают поздние ответы/ошибки прежнего объекта. Hide/pagehide и изменение фильтра инвалидируют соответствующие чтения; page navigation не меняет Bootstrap-стек или правила привязки.

Link/unlink захватывают ReceiptId/MoneyMovementId и ревизию до await; Set пары блокирует повтор, результат/error/finally ограничены текущим окном. Записывающий POST не отменяется, неизвестный исход требует обновления и сверки перед повтором.

## Проверка

Проверка типов — npm run build:ts по корневым правилам. Поведение DOM, модальных окон, камеры и запросов требует отдельных сценариев; сборка не подтверждает браузерную приёмку.

## Сопровождение

Этот файл отвечает за собственные исходники непосредственно в данной папке; для дочерних папок действуют их локальные инструкции и общие правила родителей. После изменения исходников в этой папке сверить и актуализировать здесь ответственность, контракты, зависимости и способ проверки в рамках той же задачи. При переносе файлов обновить описания прежней и новой папок. Не добавлять фиктивный журнал или неподтверждённый результат проверки.
