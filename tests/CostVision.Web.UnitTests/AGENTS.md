# Изолированные проверки Web

## Ответственность

Проект проверяет PageModel, JsonResultMapper, middleware и настройки forwarded headers с подставными зависимостями.

## Контракты и границы

Не запускать приложение для проверки handler. Прямой вызов метода не подтверждает cookie, routing, antiforgery и production DI; для них нужен отдельный разрешённый HTTP-контур.

MoneyMovementsModelTests отдельно разрешает страницу через actual layer DI extensions без хоста: connection остаётся закрытым, tracker пустым. Это проверка production registrations для конкретных constructor-зависимостей, а не приёмка production HTTP/auth-конвейера.

## Проверка

Проверять тестовые утверждения и границы их изоляции; запуск выбирать по правилам родительского AGENTS.md. Не ослаблять ожидания и не сообщать о прохождении без выполнения.

## Сопровождение

Этот файл отвечает за собственные исходники непосредственно в данной папке; для дочерних папок действуют их локальные инструкции и общие правила родителей. После изменения исходников в этой папке сверить и актуализировать здесь ответственность, контракты, зависимости и способ проверки в рамках той же задачи. При переносе файлов обновить описания прежней и новой папок. Не добавлять фиктивный журнал или неподтверждённый результат проверки.

Общая карта и порядок сопровождения: [техническое руководство](../../Documentation/TechnicalGuide/12-source-map-and-maintenance.md). Открытые изменения: [план рефакторинга](../../Documentation/Plans/project-refactoring-2026-10-13/README.md).

Stage09TransportTests проверяет actual 57 handlers с invalid ModelState и DTO-handlers с null через strict dependencies, отдельно вложенные DTO/коллекции. Reflection только в тестовом перечне. Stage09HttpTests вызывает cookie options/middleware с подставным HttpContext, включая сохранение BadHttpRequest 400/413 и очистку прежних headers; hosting/auth/antiforgery этим не подтверждаются.
