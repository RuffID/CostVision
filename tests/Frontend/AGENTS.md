# Изолированные frontend-проверки

Тесты вызывают собранные модули страницы денежных операций с минимальным подставным DOM и fetch. Перед запуском выполнить разрешённый `npm run build:ts` из CostVision.Web. Запуск: `node --experimental-strip-types --test tests/Frontend/*.test.mts`. Браузер, приложение, hosting, реальная сеть и БД не используются. Проверки контроллера подтверждают состояния, отправленные строки, счётчики и ошибки, но не Bootstrap-анимацию, фокус и браузерную приёмку.
