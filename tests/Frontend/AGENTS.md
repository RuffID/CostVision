# Изолированные frontend-проверки

boundedReads.test.mts проверяет реальные API/DOM-навигацию страниц и контроллер окна кандидатов: параметры page/filter, полный серверный count/totals, блокировку повторного перехода, сброс страницы при смене фильтра/чека и отклонение прежнего ответа. Items копий документа не обрезается по pageSize. Эти подставные DOM/fetch проверки не являются браузерной приёмкой.

Тесты вызывают собранные модули денежных операций и отчётов с минимальным подставным DOM и fetch. Перед запуском выполнить разрешённый `npm run build:ts` из CostVision.Web. Запуск: `node --experimental-strip-types --test tests/Frontend/*.test.mts`. Браузер, приложение, hosting, реальная сеть и БД не используются. Проверки import-контроллера подтверждают состояния, отправленные строки, счётчики и ошибки, но не Bootstrap-анимацию и фокус. reportTotals.test.mts проверяет отображение раздельных серверных итогов без пересчёта текущей страницы, неизвестное значение без фиктивного нуля и пять колонок магазина с копейками; браузерная приёмка остаётся открытой.
