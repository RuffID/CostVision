# Изолированные frontend-проверки

boundedReads.test.mts проверяет реальные API/DOM-навигацию страниц и контроллер окна кандидатов: параметры page/filter, полный серверный count/totals, блокировку повторного перехода, сброс страницы при смене фильтра/чека и отклонение прежнего ответа. Items копий документа не обрезается по pageSize. Эти подставные DOM/fetch проверки не являются браузерной приёмкой.

Тесты вызывают собранные модули денежных операций и отчётов с минимальным подставным DOM и fetch. Перед запуском выполнить разрешённый `npm run build:ts` из CostVision.Web. Запуск: `node --experimental-strip-types --test tests/Frontend/*.test.mts`. Браузер, приложение, hosting, реальная сеть и БД не используются. Проверки import-контроллера подтверждают состояния, отправленные строки, счётчики и ошибки, но не Bootstrap-анимацию и фокус. reportTotals.test.mts проверяет отображение раздельных серверных итогов без пересчёта текущей страницы, неизвестное значение без фиктивного нуля и пять колонок магазина с копейками; браузерная приёмка остаётся открытой.

requestCoordination.test.mts вызывает actual DOMContentLoaded точек входа dashboard/products/stores/reports/receipts/moneyMovements, receipt-link controller/API/coordinator/paging. Управляемые Promise и abort-ignoring fetch проверяют A-после-B, stale success/error/loading/finally, pagehide начальных счетов, close/reopen разных и одинаковых ID, captured command IDs/target/name, double click, изменённый create/comment draft и same-ID editor, неизвестный исход и delayed hidden. Таймеры fake DOM очищаются после теста; production exports ради тестов не добавляются. moneyMovementImport.test.mts получает строки через actual preview и проверяет File/bank/account identity, строгий preview/save lock, retained rows/counters/PDF errors, forced disposal и отсутствие автоматического POST retry.

httpContracts.test.mts проверяет actual helper/API: AbortSignal/fetch/ReadableStream, JSON/multipart/antiforgery, structured errors/status/url, envelope/обязательные данные/totals и безопасные сообщения без HTML. Cookie/routing/browser остаются отдельной приёмкой.
