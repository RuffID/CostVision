# Компонентные проверки startup и backup

## Ответственность

Прежние component tests собственного BackupService/DataBaseCheckUpService удалены вместе с этими production-путями в 08A. Наблюдаемый контракт coordinator/receipt/target/lifecycle проверяется изолированно в Infrastructure.UnitTests/DataBase/ContextRepositoryAndMaintenanceLibraryTests, DatabaseMaintenanceCoordinatorTests и DatabaseMaintenanceStartupTests. Реальная SQL/backup/restore/startup-приёмка остаётся открытой; в этой папке сейчас нет исполняемых .cs тестов.

## Контракты и границы

Эта зона может затрагивать БД, процессы и файлы; запуск отдельно разрешается. Не запускать реальные SQL-команды из документационной задачи.

## Проверка

Проверять тестовые утверждения и границы их изоляции; запуск выбирать по правилам родительского AGENTS.md. Не ослаблять ожидания и не сообщать о прохождении без выполнения.

## Сопровождение

Этот файл отвечает за собственные исходники непосредственно в данной папке; для дочерних папок действуют их локальные инструкции и общие правила родителей. После изменения исходников в этой папке сверить и актуализировать здесь ответственность, контракты, зависимости и способ проверки в рамках той же задачи. При переносе файлов обновить описания прежней и новой папок. Не добавлять фиктивный журнал или неподтверждённый результат проверки.
