# Добавление и обработка чеков

## Способы добавления

Чек можно добавить по QR-коду с камеры или изображения либо вручную. Несколько изображений обрабатываются как один набор с отдельным результатом для каждого файла.

При добавлении пользователь выбирает доступный для редактирования счёт или оставляет чек без счёта. Право просмотра общего бюджета не разрешает добавлять в него чеки.

## Обязательные данные

Для чека нужны фискальный накопитель, номер фискального документа, фискальный признак, дата, положительная сумма и известный вид операции. Эти сведения позволяют различать документы и находить повторное добавление.

Повторное добавление одинакового чека не должно создавать новую копию для того же пользователя. Если чек уже есть у пользователя, его можно добавить в другой доступный счёт. В выбранном счёте одинаковый документ повторно не появляется.

Результат сканирования показывает количество распознанных кодов, добавленных чеков и ошибок. Проблема одного изображения не должна отменять обработку остальных корректных изображений.

## Получение состава покупки

Сначала сохраняются основные реквизиты. Затем система получает подробности: магазин, адрес, продавца, позиции, количество, цену, сумму и другие сведения документа.

Обновление можно запросить вручную. Для ещё не полученных чеков выполняется ежедневная фоновая попытка; после семи неудачных попыток автоматическое обновление прекращается. Состояние и последняя ошибка позволяют понять, почему подробности ещё не появились.

Некорректные сведения не должны частично заменять сохранённую покупку. Обновление относится к тому же документу, который пользователь добавил.

## Просмотр, распределение и удаление

Список чеков ограничивается периодом и счетами. В карточке видны реквизиты, магазин, позиции и доступные связанные денежные операции.

Один чек может относиться к нескольким счетам. Перенос меняет одну привязку: исходный счёт заменяется целевым. Проверяются права изменения обоих счетов и отсутствие одинакового чека в месте назначения.

Пользователь видит в чеке только те счета и связанные операции, к которым имеет текущий доступ. Их количество и суммы считаются по тому же набору. Автор продолжает видеть собственный чек после исключения из счёта, но сведения закрытого счёта и его операций исчезают.

Только автор может переносить, отвязывать и удалять чек. После удаления исчезают его позиции и связи; соответствующие денежные операции не становятся автоматически отменёнными платежами.
