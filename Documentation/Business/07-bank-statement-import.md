# Импорт банковской выписки

## Подготовка

CostVision принимает PDF-выписки Т-Банка, СберБанка и Альфа-Банка. Пользователь выбирает банк, доступный для редактирования счёт и файл.

Документ должен содержать распознаваемый текст. Фотография или скан без текстового содержимого не подходят для такого импорта.

## Предпросмотр

Перед сохранением пользователь получает список распознанных доходов и расходов, непонятных строк и повторов. Это позволяет проверить данные и решить, какие операции сохранить.

Предпросмотр отмечает два вида повторов: уже существующие операции счёта и одинаковые строки текущей выписки.

## Обработка повторов

Повтор определяется внутри счёта по дате и времени, сумме, направлению движения и исходному описанию из выписки. Совпадение только суммы не делает разные платежи одинаковыми.

По умолчанию повтор пропускается. Замена ранее импортированной операции требует явного выбора пользователя. Повторная загрузка файла не должна незаметно увеличивать доходы и расходы.

## Результат сохранения

Результат должен ясно показывать количество созданных, обновлённых и пропущенных строк и причины ошибок с номерами строк.

Некорректные строки не сохраняются. Допустимые изменения записываются согласованно; сбой самого сохранения не должен оставлять половину записей. Если часть строк отклонена проверкой, пользователь должен видеть этот результат и иметь возможность исправить их.

Исходное описание выписки сохраняется отдельно от редактируемого комментария пользователя.

Архивный счёт не принимает сохранение импорта, включая подтверждённую замену старой строки. Сервер отклоняет такой запрос целиком до изменения операций; предпросмотр сам по себе не разрешает сохранение.
